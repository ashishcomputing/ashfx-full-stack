## 💎 The Liquid Glass Design System

Inspired by optics, fluid dynamics, and Apple/Cupertino glassmorphism, the platform features:
- **Refraction & Specular Lens Physics**: Multi-layered backdrop blurs (`backdrop-blur-2xl`), frosted translucency, and edge light reflections.
- **Dynamic Liquid Mesh Canvas**: Interactive floating glow orbs reacting smoothly to user interactions and scroll depth.
- **Purposeful Micro-Interactions**: Built using the principles of Emil Kowalski & Jakub Krehel—subtle spring physics, tactical button presses (`scale(0.98)`), and full `@media (prefers-reduced-motion)` accessibility.
- **Mobile-First Responsive Dock**: Bottom liquid glass floating dock on mobile devices for seamless one-thumb navigation.
